# DSP安全ロジック仕様書

本ドキュメントは `spec-dsp.md` と `03_behavior.md` に基づき、
DSP実装に必要な仕様を整理したものである。

---

## 1. 設計思想

### 1.1 基本原則

- LevelGuard は常時「人間の補助」である
- 主体的に音量を作らない
- 介入は必要最小限に限定される
- 介入していない状態が正常状態である

### 1.2 振る舞いのゴール

- 人間が「何もしていない」と感じること
- 問題が起きた時だけ、気づかれずに守ること

---

## 2. DSP処理の階層

DSP処理は **2つのレベル** に分かれる：

| レベル | 名称 | 目的 |
|--------|------|------|
| 1 | 曲単位DSP | 曲内のダイナミクス制御 |
| 2 | 配信全体DSP | 複数曲間のバランス制御 |

**Core Edition** では **レベル1（曲単位DSP）** を優先実装する。

---

## 3. 曲単位DSP仕様

### 3.1 時間スケール別制御

| 時間スケール | 処理 | 目的 |
|--------------|------|------|
| 短期（ms〜数十ms） | リミッター | 事故防止 |
| 中期（100ms〜数秒） | コンプレッサー | 歌唱安定 |
| 長期（10〜20秒） | ゲイン補正 | 曲全体の自然な調整 |

---

### 3.2 リミッター仕様

**目的**: True Peak による事故防止

| パラメータ | 値 | 備考 |
|------------|-----|------|
| True Peak 上限 | -1 dB | 絶対に超えない |
| Attack | 0ms（ルックアヘッド使用） | 瞬間ピーク対応 |
| Release | 10-50ms | 自然な減衰 |
| ルックアヘッド | 1-5ms | ピーク予測 |

**実装要件**:
- True Peak 計測（オーバーサンプリング対応）
- ルックアヘッドバッファ
- ゲインリダクション計算

---

### 3.3 コンプレッサー仕様

**目的**: 歌唱の安定化（サビのアタック感を潰さない）

| パラメータ | 値 | 備考 |
|------------|-----|------|
| Ratio | 2:1 〜 2.5:1 | 軽めの圧縮 |
| Attack | 10 〜 30ms | アタック感を残す |
| Release | 80 〜 150ms | 自然な復帰 |
| Knee | Soft | 滑らかな遷移 |
| Threshold | 可変（LUFS基準） | 曲の平均音量に追従 |

**禁止事項**:
- 抑揚の均し
- 表現の平坦化
- 継続的な音量誘導

---

### 3.4 長期ゲイン補正仕様

**目的**: 曲全体の自然な持ち上がり

| パラメータ | 値 | 備考 |
|------------|-----|------|
| 計測ウィンドウ | 15秒 | 長期平均LUFS |
| 最大変化率 | ±0.5 dB/s | 急激な変化禁止 |
| 目標LUFS | -14 LUFS | 配信標準 |

**ロジック**:
```
long_lufs = avg(lufs, 15s)
error = target_lufs - long_lufs
gain += clamp(error * k, -0.5dB/s, +0.5dB/s)
```

---

## 4. 使用指標

| 指標 | 用途 | 計測方法 |
|------|------|----------|
| Short-term LUFS | 歌唱の迫力度評価 | 3秒ウィンドウ |
| RMS | 中期的音量把握 | 100ms〜1秒 |
| True Peak | 事故防止 | オーバーサンプリング |
| Integrated LUFS | 曲全体の評価 | 曲単位 |

---

## 5. 介入条件

### 5.1 DSP介入状態への遷移条件

以下のいずれかが検出された場合：

- 突発的ピーク（True Peak > -1dB の兆候）
- クリップの兆候
- 曲内平均からの統計的逸脱（事故レベル）

### 5.2 介入の振る舞い

- 必要最小限の抑制を行う
- 視聴者に知覚されない速度・量で動作
- 人間フェーダー操作と競合しない

---

## 6. 非目標（実装しないこと）

- 曲構造（Aメロ／サビ）の明示的判定
- 曲中の自動フェーダー操作
- 瞬間的な最大値（Peak）のみに基づく調整
- 曲中で音量を意図的に持ち上げる処理

---

## 7. 状態マシンとの連携

| DSP状態 | CoreState | 説明 |
|---------|-----------|------|
| 待機 | IDLE | DSP未稼働 |
| 監視 | MONITORING | 計測のみ、介入なし |
| 介入 | INTERVENING | リミッター/コンプ稼働 |
| 停止 | SUSPENDED | 全処理停止 |
