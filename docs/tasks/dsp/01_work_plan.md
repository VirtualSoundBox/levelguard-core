| 1.3 | RMS 計測 | 短期RMS | RMS が計測できる |
| 1.4 | LUFS 計測 | Short-term / Integrated | LUFS が計測できる |

### Phase 2: リミッター（優先度: 高）

| # | タスク | 説明 | 完了条件 |

| 2.3 | スムージング | Attack/Release | 自然な減衰 |
| 2.4 | リミッター統合 | 処理チェーン | 正常動作 |

### Phase 3: コンプレッサー（優先度: 高）

| # | タスク | 説明 | 完了条件 |

### Phase 5: 統合（優先度: 高）

| # | タスク | 説明 | 完了条件 |

## 4. 技術仕様

### 4.1 サンプルレート

| 対応レート | 備考 |
|------------|------|
| 44100 Hz | CD品質 |
| 48000 Hz | 配信標準 |
| 96000 Hz | 高品質（オプション） |

### 4.2 チャンネル構成

| 構成 | 備考 |
|------|------|
| モノラル | 1ch |
| ステレオ | 2ch（L/R独立または連動） |

### 4.3 処理遅延（レイテンシ）

| 処理 | 遅延 |
|------|------|
| リミッター | 1-5ms（ルックアヘッド） |
| コンプレッサー | 0ms（フィードバック型） |
| 合計 | 10ms以下（仕様要件） |

## 5. テスト計画

### 5.1 計測系テスト

| テスト | 内容 |
|--------|------|
| True Peak 精度 | 既知信号での誤差 < 0.1dB |
| LUFS 精度 | EBU R128準拠 |
| RMS 精度 | 既知信号での検証 |

### 5.2 リミッターテスト

| テスト | 内容 |
|--------|------|
| ピーク制限 | -1dB を超えないこと |
| 歪み | THD < 0.1% |
| レイテンシ | 5ms以下 |

### 5.3 コンプレッサーテスト

| テスト | 内容 |
|--------|------|
| Ratio | 仕様通りの圧縮比 |
| Attack/Release | 時定数が正確 |
| Knee | 滑らかな遷移 |

---

## 6. 受け入れ基準

### 6.1 機能要件

- [ ] True Peak が -1dB を超えない
- [ ] コンプレッサーが仕様通りに動作する
- [ ] 長期ゲイン補正が ±0.5dB/s 以下で動作する
- [ ] 状態マシンと連携して動作する

### 6.2 非機能要件

- [ ] レイテンシが 10ms 以下
- [ ] CPU使用率が許容範囲内
- [ ] メモリリークがない

---

## 7. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| LUFS計測の精度問題 | 不正確な補正 | EBU R128テスト信号で検証 |
| レイテンシ超過 | 仕様違反 | ルックアヘッド最小化 |
| CPU負荷 | 配信品質低下 | SIMD最適化検討 |
