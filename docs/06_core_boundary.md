# 06_core_boundary
## Core / Pro 境界定義

本章は LevelGuard における **Core と Pro の責務境界**を定義する。
思想・信頼・課金モデルを破壊しないための、最重要ドキュメントの一つである。

---

## 1. 境界定義の前提思想

- Core は「安全装置」
- Pro は「運用を楽にする拡張」
- Pro は Core を置き換えない
- Core は Pro を前提にしない

Core 単体で思想は完結していなければならない。

---

## 2. Core に含まれるもの（確定）

Core は以下を **必ず含む**。

### 2.1 DSP 安全装置

- 統計的逸脱（事故レベル）のみを抑制
- 曲内平均音量からの逸脱検知
- フレーズ・抑揚・演出への非介入
- 人間フェーダー操作と競合しない速度・量

### 2.2 人間優先ルール

- 人間操作発生時、即座に介入停止
- 人間操作を最上位の意図として扱う
- 操作後は安全側に退避

### 2.3 フェイルセーフ

- 想定外挙動時は「何もしない」に倒す
- AI・自動処理の暴走防止
- 状態はセッション内完結

### 2.4 非機能要件（Core保証）

- 追加レイテンシ：10ms以下（暫定）
- 処理の透明性
- 再現性・予測可能性

---

## 3. Core に含めないもの（明確に除外）

以下は **Core に入れてはいけない**。

- 調整幅のユーザー設定
- プロファイル保存
- 長期学習・傾向記憶
- 視覚的に派手なUI
- 高度な自動判断ロジック

これらは思想的に Core を肥大化させる。

---

## 4. Pro に委ねるもの（拡張領域）

Pro は Core の上に **追加される**。

### 4.1 運用支援機能

- 調整幅のカスタマイズ
- プロファイル保存・切替
- 配信形態別プリセット
- 長尺配信向け状態管理

### 4.2 可視化・補助

- 状態・フェイルセーフ可視化
- ログ・履歴表示（地味でよい）
- 調整結果の説明情報

### 4.3 高度対応

- 複数 Vocal 高度制御
- 耐久歌枠向け最適化補助
- AI 補助ロジックの拡張

---

## 5. 課金モデルとの整合性

- Core：無料でも「安心して使える」
- Pro：お金を払うと「運用が楽になる」

音質・表現の優劣で差をつけない。
差は **負担軽減・管理性・拡張性**にのみ存在する。

---

## 6. 境界を壊さないための原則

- Core に設定項目を増やさない
- Core に「便利だから」は理由にならない
- 判断が必要になったら Pro 側に逃がす

境界が曖昧になった時は、必ず Core を守る。

---

## 7. 本章の役割

- 実装判断の迷いを減らす
- 課金設計のブレを防ぐ
- 将来の拡張で思想を失わない

LevelGuard は
**Core が信用されて初めて Pro が成立する**。
