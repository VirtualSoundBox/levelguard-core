# 05_non_goal
## Coreで「やらないこと」定義（非目標）

本章は LevelGuard Core が
**意図的に実装しないこと**
**将来も責務外とすること**
を明文化する。

誤った期待・過剰実装・思想崩壊を防ぐための章である。

---

## 1. 判断系の非目標

LevelGuard Core は以下を行わない。

- 曲の感情を評価しない
- 楽曲ジャンルを判断しない
- 盛り上がり・サビを検出しない
- 歌唱の上手さ・完成度を判断しない
- 演奏技術を評価しない

音楽的判断は常に人間の責務である。

---

## 2. 表現介入の非目標

Core は音楽表現を作らない。

- 抑揚を整えない
- ダイナミクスを均さない
- 音圧を最適化しない
- 聴きやすさを主観的に改善しない

「事故防止」以外の音量変化は不正である。

---

## 3. 視聴者依存処理の禁止

以下は Core の思想と完全に相反する。

- コメント量で音量を変える
- 同接数で挙動を変える
- 投げ銭・リアクションに反応する
- 盛り上がりを数値化して反映する

LevelGuard は配信演出装置ではない。

---

## 4. 自律制御の否定

Core は「自分で判断してやり続ける」存在ではない。

- 長時間の自動最適化を行わない
- 人間不在を前提にしない
- 無人運用を想定しない

人間が操作している前提が崩れた時点で、
Core は守りに徹する。

---

## 5. 学習・記憶の非目標

Core は以下を保持しない。

- 過去配信の傾向
- 歌唱者の癖
- 配信者ごとの最適値
- セッションを跨ぐ学習結果

状態は常に「今この瞬間」のみを扱う。

---

## 6. Pro領域への明確な線引き

以下は Core では扱わないが、
将来的に Pro で扱う可能性がある。

- 調整幅のカスタマイズ
- プロファイル保存
- 高度な複数Vocal制御
- 長尺配信向け最適化
- 可視化・ログ強化

Core にこれらを入れることは設計違反とする。

---

## 7. 非目標定義のゴール

- 実装者が「ここまでやっていい」と勘違いしない
- 利用者が「できるはず」と期待しすぎない
- 思想を静かに守る

LevelGuard Core は
**少ないことを正しくやる**ための存在である。
