# 09_core_parameters
## Core 固定パラメータ定義（設計基準）

本章では LevelGuard Core において
**存在してよいパラメータ／存在してはいけないパラメータ**を定義する。

目的は以下の3点である。

- 実装の自由度を必要以上に広げない
- 利用者に「調整地獄」を与えない
- Pro との思想的・機能的境界を明確にする

---

## 1. Core パラメータ設計の基本思想

Core は以下を満たす必要がある。

- 初期値のままで安全に使える
- 利用者が判断に迷わない
- 音楽的意図を破壊しない

そのため Core では
**「調整可能であること」自体を価値としない。**

---

## 2. Core に存在してよいパラメータ

以下は Core 内部に存在してよいが、
**ユーザーからは直接操作できない**。

### 2.1 事故判定用統計ウィンドウ

- 短期平均算出時間
- 分散・偏差計測用サンプル数

理由：
- 実装上必要
- 利用者が理解・調整する意味がない

---

### 2.2 介入最大時間

- 1 回の Intervention が継続できる最大時間
- 無限補正防止用

理由：
- 安全装置として必須
- 人間の操作を上回ってはならない

---

### 2.3 安全域しきい値（内部定数）

- 事故レベル判定用しきい値
- クリップ・破綻防止目的

理由：
- Core の責任範囲
- 配信者ごとに変えるべきではない

---

## 3. Core に存在してはいけないパラメータ

以下は **Core では絶対に持たない**。

### 3.1 調整幅（補正量）の指定

- 最大±何 dB まで許可するか
- どれくらい積極的に補正するか

理由：
- 音楽的判断になる
- 利用者の意図が介入する領域
- Pro 機能と明確に競合する

---

### 3.2 プロファイル関連設定

- シーン別設定
- 歌枠／雑談枠切り替え
- 個人最適化パラメータ

理由：
- Core は「その場の安全」を担う
- 継続的最適化は Pro の役割

---

### 3.3 AI 介入度・信頼度しきい値

- AI ON / OFF
- 介入頻度制御

理由：
- Core は AI に依存しない
- 判断の複雑化を避ける

---

## 4. 固定値であることの明文化

Core におけるパラメータは
**「調整不可であることが仕様」**である。

これは以下を意味する。

- UI で露出しない
- config に書かせない
- API で触らせない

※ 実装内部で変更可能であっても、
　 利用者が触れる経路は一切持たせない

---

## 5. Pro への拡張余地（境界線）

以下は Core では固定だが、
**Pro では解放され得る**。

- 介入量の上限
- 状態遷移の可視化レベル
- プロファイル保存対象

本章は「禁止」ではなく
**役割分担の宣言**である。

---

## 6. 実装者向け注意

- 「設定できた方が親切」という発想は禁止
- 迷ったら Core から削る
- 後から Pro に逃がす設計を前提にする

---

## 7. 本章の位置づけ

本章は Core の
**操作不能であることによる安全性**
を保証する定義である。

この制約を破った時点で、
それは Core ではない。
