# 00_concept | LevelGuard Core

## 概要
LevelGuard Core は、配信・収録・ライブ用途において**音量事故を未然に防ぐための安全装置（Safety Guard）**として設計された OSS コンポーネントです。

本プロジェクトの目的は「音を良くすること」ではなく、**壊さないこと・事故らせないこと**にあります。

---

## なぜ LevelGuard が必要か

音楽配信や歌枠、複数入力を伴う配信環境では、以下のようなリスクが常に存在します。

- 突発的な大音量（シャウト・咳・笑い）
- マイク位置や入力ゲインの変動
- 複数ボーカル・複数入力のレベル干渉
- 長時間配信による疲労・判断力低下

これらは「操作ミス」ではなく**構造的に起こる事故**であり、
人間の注意力や経験だけで完全に防ぐことは困難です。

LevelGuard Core は、こうした事故を**自動かつ機械的に抑止する最後の防波堤**として機能します。

---

## 設計思想

### 1. Safety First

LevelGuard Core の最優先事項は安全です。

- 音質改善や演出効果は目的としない
- ユーザーの判断に委ねない
- 常に「最悪ケース」を基準に動作する

Core は「うまくやる」のではなく、
**「やらかさない」ために存在します。**

---

### 2. 自動・不可逆・最小限

Core の挙動は以下を満たすよう設計されます。

- **自動**：手動操作を必要としない
- **不可逆**：危険判定後は即座に抑制する
- **最小限**：必要以上の介入は行わない

これにより、
- 設定ミス
- 過信
- 過度なチューニング

といった人為的リスクを排除します。

---

### 3. 設定しないという設計

LevelGuard Core では、ユーザーが調整できるパラメータは極力持ちません。

理由は以下の通りです。

- 調整幅は事故の入口になり得る
- 安全装置に「好み」を持ち込まない
- 再現性・検証性を保つ

Core は**決め打ちの安全基準**を提供し、
調整や最適化の余地は拡張エディション（Pro）に委ねます。

---

### 4. OSS としての Core

LevelGuard Core は OSS として公開されます。

- 動作原理が確認できる
- ブラックボックスにならない
- 信頼性をコードと仕様で担保する

安全装置である以上、
**「中身が見えない」こと自体がリスク**と考えます。

---

## Core と Pro の関係

LevelGuard Core は「最低保証ライン」です。

- Core 単体で事故防止として完結する
- Pro がなくても実用に耐える
- Pro は Core を置き換えない

Pro Edition は、

- 調整幅の拡張
- プロファイル管理
- 高度な可視化・耐久配信向け機能

などを提供しますが、
**Core の思想・安全制約を破ることはありません。**

---

## 非目標（Non-Goals）

LevelGuard Core は以下を目指しません。

- コンプレッサーやリミッターの代替
- 音作り・演出用途
- 配信者のスキルを不要にすること

Core はあくまで「最後の安全装置」であり、
表に出る存在ではありません。

---

## まとめ

LevelGuard Core は、

> **人間がミスをする前提で作られた、安全のための仕組み**

です。

この思想は、
今後どのような拡張やエディションが生まれても
変わることはありません。
