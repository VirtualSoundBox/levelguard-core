# 07_core_feature_list
## Core 機能定義一覧（実装基準）

本章は LevelGuard Core に **実装される機能を確定**するための一覧である。
ここに書かれていない機能は Core に実装してはならない。

---

## 1. Core の提供価値

Core は以下を提供する。

- 音量事故を防ぐ
- 人間の操作を邪魔しない
- 意図しない挙動を起こさない
- 導入しても音が変わったと気づかれない

「安心して刺しっぱなしにできる」ことが唯一の価値である。

---

## 2. 入力・前提条件

### 2.1 対象信号

- マイク入力（Vocal想定）
- モノラル / ステレオは問わない
- 外部情報（視聴者数・コメント等）は使用しない

### 2.2 想定環境

- OBS 等の配信ソフト
- リアルタイム処理
- セッション単位で完結

---

## 3. Core 機能一覧（確定）

### 3.1 音量監視機能

- 曲内平均音量を基準とした統計監視
- 一定時間窓での RMS / Loudness 計測
- 異常値（事故レベル）の検出

※ 音楽的抑揚・意図的強弱は対象外

---

### 3.2 事故抑制処理（DSP）

- 瞬間的な過大音量の抑制
- 視認できない速度・量での制御
- フェーダー操作として知覚されない挙動

※ 常時補正ではなく「必要時のみ」

---

### 3.3 人間操作検知

- フェーダー / ゲイン操作の検知
- 人間操作発生時の即時介入停止
- 操作終了後の安全退避状態遷移

---

### 3.4 自動処理停止機構

- 想定外状態検知時の自動停止
- 連続異常検出時の処理無効化
- 停止後は自動復帰しない

---

### 3.5 状態管理（最小限）

- 通常
- 監視中
- 介入中
- 停止

※ 状態は内部のみで保持し、UI 表示は必須としない

---

## 4. Core が保持してよい情報

- セッション内の音量統計値
- 一時的な状態フラグ
- 直近の異常検出履歴（短期）

以下は禁止：

- 永続データ保存
- プロファイル
- 学習結果の保持

---

## 5. Core に存在してよい UI

- ON / OFF
- 現在状態の簡易表示（任意）

以下は禁止：

- 調整スライダー
- 詳細設定画面
- 視覚的演出

---

## 6. 実装判断のための原則

判断に迷った場合、以下を自問する。

- これは「事故防止」か？
- 人間操作より優先されるか？
- 無くても安全か？

一つでも NO があれば Core に入れない。

---

## 7. 本章の役割

- 実装スコープの固定
- 機能追加圧の遮断
- Pro との境界維持

Core は **少なく、強く、信用される**ことを優先する。
